# 推荐标签

三个维度，每个 issue 各取其一。颜色与描述随标签定义，创建时由脚本应用

## 类型

- type:bug（d73a4a）：bug
- type:feature（a2eeef）：feature

## 优先级

- priority:P1（b60205）：urgent
- priority:P2（d93f0b）：high
- priority:P3（fbca04）：normal
- priority:P4（0e8a16）：low

## 阶段

- stage:needs-triage（ededed）：待分诊
- stage:needs-info（d455d0）：缺信息
- stage:ready-for-agent（8fc951）：可交给 agent
- stage:ready-for-human（0052cc）：需要人处理
- stage:wontfix（6f42c1）：不修复
