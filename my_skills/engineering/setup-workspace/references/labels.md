# 推荐标签

三个维度，每个 issue 各取其一。颜色随标签定义，创建时由脚本应用

## 类型

- type:bug（红）：意外行为
- type:feature（青）：新功能请求

## 优先级

- priority:P1（深红）：紧急，先处理
- priority:P2（橙红）：重要
- priority:P3（黄）：正常
- priority:P4（绿）：可推迟

## 阶段

- stage:needs-triage（灰）：待分诊，赋优先级后移除
- stage:needs-info（紫）：缺信息，等待补充
- stage:ready-for-agent（亮绿）：可交给 agent 处理
- stage:ready-for-human（蓝）：需要人处理
- stage:wontfix（深紫）：不修复，关闭
