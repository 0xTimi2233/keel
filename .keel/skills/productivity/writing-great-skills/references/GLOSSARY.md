# Skill 编写核心术语表

- **Context Load**: 描述与指令占用上下文窗口的体积与认知成本。
- **Completion Criteria**: 判定某个步骤是否彻底完成的二元可查验条件。
- **Progressive Disclosure**: 将次要参考资料下沉到子文件，并在主文档中使用显式 Markdown 链接按需加载的模式。
- **No-op Sentence**: 对 Agent 行为没有任何实质约束或改变的无效句子。
- **Leading Word**: 能够唤醒模型预训练先验知识的高密度专业词汇。
- **Single Source of Truth**: 某个规则或定义的唯一权威出处。
