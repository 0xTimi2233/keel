# GLOSSARY.md 格式规范

`GLOSSARY.md` 是此教学工作区的规范语言。所有概念讲解、练习和学习记录都应遵循其术语体系。构建该文件本身就是学习的一部分：将概念压缩为精炼的定义是用户理解它的有力证据。

## 结构

```md
# {Topic} 词汇表

{一到两句话描述该词汇表涵盖的主题。}

## 术语 (Terms)

**Hypertrophy**：
通过重复训练环节中的机械张力和代谢压力驱动的肌肉增长。
_应避免使用_：增肌、变大

**Progressive overload**：
随着时间的推移，系统性地增加对肌肉的要求 — 通过重量、容量或强度。
_应避免使用_：推得更有力、升级

**RPE (Rate of Perceived Exertion)**：
对一组训练感觉有多难的 1–10 自自我评分，其中 10 为力竭，8 意味着组内还能做两次。
_应避免使用_：努力程度得分、强度评分
```

## 规则

- **仅在用户理解某个术语时才添加它。** 词汇表是压缩知识的记录，而不是供用户通过阅读来学习的字典。如果用户刚刚被引入某个概念，请等待直到他们能够正确使用它，然后再将其提升到这里。
- **要有明确偏好。** 当同一个概念存在多个词汇时，选择最合适的一个，并将其他词汇列为应避免的别名。语言就是这样压缩的。
- **保持定义精炼。** 一两句话即可。定义该术语“是什么”，而不是它“做什么”或“如何做”。
- **在定义内部使用词汇表自身的术语。** 一旦某个术语进入词汇表，在任何地方都优先使用它 — 包括在其他定义内部。这能让复杂的术语在日后更容易被掌握。
- **当出现自然聚类时在二级标题下分组**（例如 `## 解剖学`、`## 计划制定`）。当术语本身很紧密时，平铺列表即可。
- **显式标注歧义。** 如果某个术语在更广泛的领域中使用松散，记录其消除歧义的约定：“在本工作区中，'set' 始终表示正式组 — 预热组会被单独追踪。”
- **随着理解的加深进行修订。** 用户在第一周编写的定义到第六周可能是错误的。原地更新；不要留下过时的条目。
