description: 针对高信任度的原始凭据调查问题，并将研究结果作为 Markdown 文件捕获在仓库中。当用户希望研究某个主题、收集文档或 API 事实，或者将阅读整理工作委托给后台代理时使用。
---

启动一个**后台代理**来执行研究，以便在其阅读分析时你可以继续工作。

它的职责：

1. 针对**原始凭据**调查问题 — 官方文档、源代码、规范、第一方 API — 而不是针对它们的二次编写内容。追溯每个论点直至归属的原来源。
2. 将研究结果写入单个 Markdown 文件，并注明每个论点的来源出处。
3. 将其保存在仓库已有此类笔记的位置；匹配现有的约定，如果没有，则将其放在合理的位置并说明具体路径。
