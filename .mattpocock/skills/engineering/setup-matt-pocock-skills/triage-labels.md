# 分类标签（Triage Labels）

这些 Skill 基于五个规范分类角色来表述逻辑。本文件将这些角色映射到此仓库 issue 追踪器中实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue                    |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                    |
| `ready-for-agent`          | `ready-for-agent`    | 已完整规范化，准备好交给离线 Agent 处理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工来进行实现                        |
| `wontfix`                  | `wontfix`            | 不会采取行动                             |

当 Skill 提及某个角色时（例如“应用离线 Agent 就绪分类标签”），请使用本表对应的标签字符串。

编辑右侧列以匹配你实际使用的任何词汇。
